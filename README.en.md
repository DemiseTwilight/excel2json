# excel2jsonForUnity
This is a Unity version based on excel2json, with the command line removed and dependencies integrated.
For the C# and GUI versions of excel2json, see: https://github.com/neil3d/excel2json.git

For detailed help documentation, see:
[https://neil3d.github.io/coding/excel2json.html](https://neil3d.github.io/coding/excel2json.html)

## Configuration File Settings
You can set paths and optional parameters through the Excel2JsonConfig configuration file.

## Dependencies
All dependencies are included in the Libs folder. If you want to use your own JSON parser, please delete Newtonsoft.Json.dll and modify some code accordingly.
